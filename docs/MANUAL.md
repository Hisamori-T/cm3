## 1. ログイン・基本操作

### ログイン

1. ブラウザで `https://cmv3.fact-ally.com` を開く
2. 管理者から発行されたメールアドレスとパスワードを入力して **ログイン** をクリック

> **ブックマーク推奨**：スマートフォンでも同じURLにアクセスできます

### 画面の構成

```
┌─────────────────────────────────────────────────────┐
│  CL  Construction Mgr    ページ名    [アクションボタン] │  ← 上部バー
├──────────┬──────────────────────────────────────────┤
│ ダッシュ  │                                          │
│ 案件一覧  │                                          │
│ ─作業─  │                                          │
│ カンバン  │           メインコンテンツ                │
│ 全社工程  │                                          │
│ 日報     │                                          │
│ カレンダー│                                          │
│ 承認待ち  │                                          │
│ 発注管理  │                                          │
│ 業者マスタ│                                          │
│ 顧客マスタ│                                          │
│ ─データ─ │                                          │
│ CSV出力  │  ← 管理者・経理・上長のみ表示              │
│ ─設定─  │                                          │
│ 管理者設定│  ← 管理者のみ表示                        │
└──────────┴──────────────────────────────────────────┘
```

- 左側のサイドバーでメニューを切り替えます
- 上部バー右端のボタンでページごとのアクション（新規作成・保存など）が実行できます

### ログアウト・プロフィール変更

- 画面左下のアバター（名前の頭文字）をクリック → **プロフィール** または **ログアウト**

## 2. ダッシュボード

**URL**：`/dashboard`

経営状況をひと目で把握するトップページです。

| カード | 内容 |
|---|---|
| 売上合計 | 今月の受注・請求合計金額 |
| 進行中案件数 | ステータス「着工〜施工中」の案件数 |
| 利益率 | 全案件の平均営業利益率 |
| ステータス分布 | 7段階ステータス別の案件数内訳 |
| 月別推移グラフ | 過去12ヶ月の売上推移 |
| 利益率ランキング | 案件別の利益率トップ10 |
| 売掛金サマリー | 今月請求額・入金待ち合計・期限超過合計 |
| 未入金アラーム | 入金期限を超過した請求書の一覧（赤表示） |
| 担当者別稼働時間 | 今月の日報から集計した各担当者の稼働時間 |

## 3. 案件管理

### 3-1. 案件一覧

**URL**：`/projects`

- 工事番号・工事名・ステータス・案件立場・担当者・工期をまとめて一覧表示
- 上部の検索ボックスで工事名・発注者名をキーワード検索可能
- ステータスタブでフィルタリング（全件 / 見積中 / 受注 / 着工 など）

### 3-2. 新規案件の作成

1. 案件一覧の右上 **＋ 新規作成** ボタンをクリック
2. 工事名・発注者（顧客マスタから検索または直接入力）・工事場所を入力
3. 工事番号は `{年}-{社員番号}-{連番}` で**自動採番**されます（手動変更可）
4. **作成** をクリック → 案件詳細画面へ移動

> 発注者欄では顧客マスタを検索して選択できます。マスタに登録済みの顧客を選ぶと「✓ マスタ連携済」バッジが表示されます。

### 3-3. 案件詳細タブ一覧

案件を開くと上部にタブメニューが並びます。

| タブ | 内容 |
|---|---|
| **工事台帳** | 案件の基本情報・担当者・工期・ステータス・承認スタンプ・原価集計 |
| **QCDS** | 原価算定表（直接工事費・現場経費・利益逆算） |
| **業者見積** | 業者から届いた見積の管理・AIスキャン |
| **顧客見積** | 顧客向け見積書の作成・PDF出力 |
| **注文書** | 顧客への注文書作成 |
| **注文請書** | 顧客からの注文請書管理 |
| **請求書** | 請求書の作成・PDF出力・入金記録 |
| **進捗** | 写真・図面・施工記録の投稿 |
| **工程表** | 案件内のガントチャート |
| **出面** | 作業員・業者の出面記録（天候・KY実施） |
| **写真台帳** | 現場写真の整理・出力 |
| **発注書** | 業者への発注書作成 |
| **編集履歴** | 誰がいつ変更したかの全履歴 |

### 3-4. 案件情報の編集

1. 工事台帳タブを開く
2. 「**案件情報**」カードヘッダーの右端 **編集** ボタンをクリック
3. 各項目を修正 → **保存** ボタン（同じ位置に切り替わります）

> 担当者欄（「**担当者**」カード）にも同様に編集ボタンがあります

### 3-5. ステータス変更

詳細タブの上部にある 7段階のボタンをクリックするだけで変更できます。

```
見積中 → 受注 → 着工 → 施工中 → 完工 → 請求済 → 入金済
```

> ステータスが変更されると、Slack通知が設定されている場合は自動でチャンネルに通知されます。

> 変更権限：管理者・マネージャー・作成者本人のみ

### 3-6. カンバンビュー

**URL**：`/projects/kanban`

ステータス別の案件カードをドラッグ＆ドロップで移動できます。全体の進捗状況を視覚的に把握するのに便利です。

## 4. 工事台帳

**URL**：`/projects/{id}`（案件詳細の最初のタブ）

クラップ独自の工事台帳ページです。案件の基本情報・承認スタンプ・原価集計をまとめて管理します。

### 4-1. 画面構成

| エリア | 内容 |
|---|---|
| 左カラム（基本情報） | 工事番号・工事名・発注者・工期・担当者など。黄背景のセルは手動入力が必要な項目 |
| 右カラム（承認スタンプ） | 担当者・現場担当・営業担当・確認・承認の5枠。承認依頼を送ると押印される |
| 案件・受注情報 | 案件立場・受注金額・目標営業利益 |
| 工事割出テーブル | 実行予算・取決見通・精算見通の3列比較 |
| 月別精算見通 | 月ごとの支払見通し（セルをクリックで直接入力） |

### 4-2. PDF・Excel出力

工事台帳タブの右上に出力ボタンがあります。

| ボタン | 内容 |
|---|---|
| **PDF出力**（赤） | WeasyPrint で工事台帳PDFを生成・ダウンロード |
| **Excel出力**（緑） | 既存Excelテンプレートに値を埋め込んでダウンロード |

### 4-3. 承認スタンプ

1. 右上の **承認依頼** ボタンをクリック
2. 各ステップの担当者を選択（前回の設定が自動で入力されます）
3. **送信** → 承認者のメニューに「承認待ち」として表示される
4. 承認されると工事台帳の印影欄に自動で押印される

## 5. QCDS（原価算定）

**URL**：`/projects/{id}/qcds`

クラップ独自の原価算定表です。

### 5-1. 主要タブ

| タブ | 内容 |
|---|---|
| 原価集計 | 直接工事費・現場経費・一般管理費の集計 |
| 実行予算 | 各工種の予算入力 |
| 取決見通 | 受注後の見通し修正（発注書ステータス変更で自動更新） |
| 精算見通 | 完工後の精算 |
| 業務マスタ | 経費率・保険料率・人件費単価の設定 |

### 5-2. 利益逆算テーブル

工事原価から目標利益率を複数設定すると、顧客に提示すべき見積金額を自動計算します。

- **印紙税**も工事金額に応じて自動算定されます

### 5-3. 業者見積スキャンとの連携

業者見積をAIスキャンして明細を取り込むと、直接工事費テーブルの各行の右端 **[▼]** をクリックするとスキャン明細のアコーディオン表示が可能です。

## 6. 顧客見積書

**URL**：`/projects/{id}/quote`

### 6-1. 見積書の作成

1. 見積タブを開く → **＋ 新規見積** をクリック
2. 大項目（工種）と明細を入力
3. 値引き・消費税が自動計算されます

### 6-2. 承認スタンプ（電子捺印）

1. 見積書を開く → 右上の **承認依頼** ボタン
2. 担当・確認・承認 の各ステップに担当者を設定して送信
3. 承認者が承認すると、担当者の苗字がスタンプとして記録されます
4. 見積書を変更するとスタンプは**自動でリセット**されます（改ざん防止）

### 6-3. PDF・Excel出力

- 見積書詳細画面 右上 **Excel出力** または **PDF** ボタン
- PDF：3部構成（表紙 / 総括表 / 大項目別明細）

## 7. 業者見積スキャン（AI）

**URL**：`/projects/{id}/estimate`

業者から届いた紙・PDFの見積書をAI（Gemini）が読み取り、QCDS・見積書に自動転記します。

### 手順

1. 業者見積タブを開く
2. 左パネルのD&Dゾーンに業者見積のPDF / 画像ファイルをドロップ（またはクリックしてファイル選択）
3. AI解析が完了するまで待つ（数十秒〜2分程度）
4. 解析結果を**必ず確認**してから「QCDS/見積に反映」をクリック

> 解析結果は必ずユーザーがレビューしてから反映してください。数値の誤読が発生する場合があります。

## 8. 注文書・注文請書

### 注文書（`/projects/{id}/order`）

注文書は「顧客がクラップへ工事を発注する書類」です。

1. 注文書タブを開く
2. **案件から適用** ボタン（緑）をクリック → 案件情報・見積金額・工期が自動入力
3. 工事内容・適要・支払条件を確認・修正
4. **保存** → **PDF出力** で取引先に送付

#### ステータス管理

```
下書き → 発行済み → 締結済み → 取消
```

「発行済み」に変更すると注文請書が自動で作成されます。

### 注文請書（`/projects/{id}/acknowledgment`）

受け取った注文請書を管理します。承認スタンプで受領確認を記録できます。

- **PDF出力** ボタンで注文請書PDFを出力

## 9. 請求書・入金管理

**URL**：`/projects/{id}/invoice`

### 9-1. 請求書の作成

1. 請求書タブ → **＋ 新規請求** をクリック
2. 請求金額・消費税・支払期日を入力
3. **PDF出力** で取引先に送付

### 9-2. 入金記録

請求書の詳細画面から入金を記録できます。

1. 請求書を開く → **＋ 入金記録** をクリック
2. 入金日・入金額を入力 → **保存**
3. 請求金額に達すると自動でステータスが「入金済」に変わります

> ダッシュボードの「未入金アラーム」で入金期限超過の請求書を確認できます。

## 10. 発注書管理

**URL**：`/purchases`（全社）または `/projects/{id}/purchase`（案件内）

業者への発注書を作成・管理します。

### 10-1. 発注書の作成

1. 発注書タブ → **＋ 新規発注書** をクリック
2. 業者をドロップダウンから選択
   - 選択時に過去の見積履歴がある場合、明細に自動追加するか確認が表示されます
3. 明細を確認・編集して保存
4. **PDF出力** で業者に送付

### 10-2. AIスキャン取込

発注書作成フォーム上部のD&Dゾーンに業者から受け取ったPDF/Excelをドロップすると、AIが明細を自動認識して取り込みます。

### 10-3. ステータスと取決連動

発注書のステータスを「発注済」に変更すると、QCDS原価算定表の「取決金額」列が自動で更新されます。

各投稿の右上にある **×** ボタンで削除できます（権限チェックあり）。

## 13. カレンダー・担当者スケジュール

**URL**：`/calendar`

**「誰がいつどこの現場にいるか」と「どの現場で何人出面したか」を1画面で把握できます。**

### 画面の見方

カレンダーの各日付にカラーチップが表示されます：

| 色 | 種類 | 内容 |
|---|---|---|
| シアン（青緑） | **担当者スケジュール（現場）** | 現場訪問の予定（誰がどの現場へ） |
| 緑 | **日報（提出済）** | その日に提出された日報の現場名 |
| 紫 | **出面** | その日に記録された出面（業者名・人工数）|
| 紫（薄） | 打合せ | 社内・客先との打合せ |
| 赤 | マイルストーン | 重要な節目（検査・引渡など） |
| 橙 | 業者訪問 | 業者との打合せ |
| グレー | その他 | 個人予定・有給など |

### 出面チップの見方

紫のチップには `🔨 業者名 N人工` と表示されます。日付をクリックすると右側の詳細パネルに出面の詳細が表示されます。

### 日付をタップすると日詳細パネルが開きます

右側に当日のイベント・日報・出面が一覧表示されます。

### 担当者スケジュール（現場訪問予定）の登録

1. 登録したい日付をクリック → 日詳細パネルを開く
2. **＋ イベント追加** をクリック
3. 種別を **「現場」** に変更
4. 案件をドロップダウンから選択
5. 担当する社員にチェックを入れる（複数可）
6. 日時を設定 → **保存**

> 「現場」種別で登録すると、カレンダーにシアン色で表示されます

### イベントの削除

日詳細パネルのイベント一覧の右端 **×** をクリック

## 14. 日報

日報は2つの方法で入力できます。

### 方法①：カレンダーから入力（推奨）

1. `/calendar` を開く
2. 入力したい日付をクリック → 日詳細パネル
3. **＋ 日報を書く**（緑ボタン）をクリック
4. 天気・案件・作業内容・開始/終了時刻を入力
5. 複数の現場を掛け持ちした場合は **「＋ 案件を追加」** で行を追加
6. **提出する** をクリック

### 方法②：日報ページから入力

**URL**：`/daily-report`

1. 右上の **＋ 日報を書く** をクリック
2. 同様のフォームで入力・提出

### 日報の確認・修正

- 日報ページのタイムラインで過去の日報を確認
- 自分の日報（または管理者）は鉛筆アイコンから修正可能

## 15. 出面台帳

**URL**：`/projects/{id}/attendance`

現場ごとの作業員・業者の出面（人工）を記録します。

### 15-1. 出面の記録

1. 案件詳細の **出面** タブを開く
2. 右上 **＋ 出面追加** をクリック
3. 以下の項目を入力：

| 項目 | 内容 |
|---|---|
| 出面日 | カレンダーから選択 |
| 業者 | ドロップダウンから選択（発注書に紐づく業者が上部に表示） |
| 作業員数（人工） | 例：3.0 |
| 天候 | 晴れ / 曇り / 雨 / 雪 / 強風 から選択 |
| KY実施 | KY（危険予知）ミーティングを実施した場合はチェック |
| 発注書 | 関連する発注書があれば選択（任意） |

4. **保存** をクリック

### 15-2. 出面一覧の確認

記録された出面は月ごとのカレンダー（カスタムナビゲーター）とサマリーテーブルで確認できます。

| 列 | 内容 |
|---|---|
| 日付 | 出面日（日報へのリンクボタン付き） |
| 業者 | 業者名 |
| 人工 | 作業員数 |
| 天候 | 天候アイコン |
| KY | KY実施の場合「✓」バッジ |

### 15-3. QCDS との比較

サマリーテーブルでは業者ごとに「QCDS取決」の予算金額と実績を比較して表示します。

### 15-4. カレンダーとの連携

出面を記録すると、カレンダーページの該当日に紫色の出面チップが自動で表示されます。

## 16. 承認ワークフロー

**URL**：`/approvals`

見積書・工事台帳の承認依頼の確認・操作を行います。

### 画面の見方

ページは4つのセクションに分かれています：

| セクション | 内容 |
|---|---|
| **あなたの承認待ち**（黄） | 自分が承認者として指定された未承認の依頼 |
| **差し戻された案件**（赤） | 差し戻しを受けた依頼 |
| **依頼中**（青） | 自分が送信した承認依頼の状態 |
| **完了済み**（緑） | 承認が完了した依頼 |

### 承認の操作

1. 「あなたの承認待ち」セクションの案件行をクリック → 見積書ページへ移動
2. 見積書ページ右上の承認ボタンから「承認」または「差し戻し」を実行

### 工事台帳の押印依頼

工事台帳の承認依頼は「工事台帳 押印依頼」セクションに別途表示されます。

## 23. 困ったときは

### よくある質問

**Q：ログインできない**  
A：管理者にパスワードの再設定を依頼してください。

**Q：案件が編集できない**  
A：編集権限は「管理者 / マネージャー / 案件の作成者本人」のみです。権限変更は管理者に依頼してください。

**Q：見積書のPDFが出力されない**  
A：ブラウザのポップアップブロックが有効な場合、PDFが開かれないことがあります。ポップアップを許可する設定をお試しください。

**Q：業者見積のAI解析が遅い / 失敗する**  
A：スキャン品質が低い画像は読み取り精度が落ちます。解像度300dpi以上のPDFをお使いください。解析失敗時は数分待って再試行してください。

**Q：日報を間違えて提出した**  
A：日報ページまたはカレンダーから鉛筆アイコンで修正できます（自分の日報のみ。管理者は全員分修正可）。

**Q：案件を誤って作成してしまった**  
A：案件は論理削除（非表示）のみ対応しています。誤作成の場合は管理者に連絡してください。

**Q：CSVをExcelで開くと金額が「1.23E+07」のような表示になる**  
A：ExcelでCSVを開いた後、金額列を選択して「書式設定」→「数値」に変更してください。または、Excelの「データ取込」機能でCSVを開くと書式を指定できます。

**Q：出面を記録したのにカレンダーに表示されない**  
A：カレンダーページをリロード（F5）してください。月をまたいで移動した後に表示される場合もあります。

**Q：CSV出力メニューが表示されない**  
A：CSV出力は管理者・最高管理者・上長・経理のみ利用できます。権限が必要な場合は管理者に申請してください。
